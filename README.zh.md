# dsh-qq-archive

按配置保存 DSH 消息事件。启用前必须明确选择租户、账号，以及群或私聊对象；这些条件取交集，不是账号与群的配对列表。不同会话使用独立 SQLite 文件。本插件不向模型注册查询或导出工具。

插件仍在开发中，暂不适合发布。归档包含规范化消息正文和不透明的媒体引用，不包含图片或语音文件本体；传输层未收到的消息无法恢复。容量不足、消息 ID 内容冲突和超时均会报告，不自动重试。超时表示写入结果不确定，可能已经写入；重试前应核对归档。

SQLite 文件不加密，依赖主机文件权限保护，不能抵御有特权的本机用户。归档可能包含个人聊天，请只选择有权保存的会话，并按实际使用场景保护数据。

需要 Node ^22.19 或 >=24、DSH 0.2.2-rc.1 和兼容的 `dsh-im-kit` 传输插件。附带的 bundle 默认关闭。开启前配置租户、网络、账号以及群或私聊对象；`allowAnyTenant`、`allowAnyAccount` 只放宽对应维度，不会取消会话选择。默认目录为当前 profile 的 `data/qq-archive`；自定义目录必须为绝对路径。

状态服务仅提供计数和错误码，不提供消息正文或身份信息。目前没有自动删除、历史消息重放、迁移、媒体下载和界面配置。`npm test` 仅使用合成数据；不要将测试指向生产 profile 或数据库。
